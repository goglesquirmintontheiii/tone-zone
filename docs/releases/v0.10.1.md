Tone Zone **0.10.1**: sound on a Raspberry Pi with a desktop, the input channel picker and a test tone.

### Install
Download `Tone-Zone-0.10.1-x86_64.AppImage`, `chmod +x` it and run. On the Pi, run the install command again (it adds two packages the fix needs):

```
curl -fsSL https://github.com/goglesquirmintontheiii/tone-zone/releases/latest/download/install.sh | sudo bash
```

### Raspberry Pi
- **Sound on a Pi with a desktop:** the engine now joins the desktop's PipeWire through PipeWire's own JACK library, with your buffer size, instead of looking for a JACK server that isn't there ("jack server is not running"). The installer adds `pipewire-jack` and `acl` on a Pi that runs PipeWire.
- **The engine is wired to your device:** the Pi now connects the engine's input and outputs to the chosen device itself, with plain JACK too. Before, nothing made those links, so there was no sound in either mode.
- **Input channel:** pick which input of the device feeds the engine. On a Line 6 Helix, USB 7 is the dry guitar and USB 1/2 is the Helix's own sound.
- **Test tone:** the Audio section plays a 440 Hz or 1 kHz sine, pink noise or a sweep, on both sides or one, at a level you set (never above -6 dBFS). It replaces the preset while it plays and stops by itself after 30 seconds.

### Fixes
