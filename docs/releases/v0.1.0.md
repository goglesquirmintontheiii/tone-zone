First release of **Tone Zone**, a realtime guitar & bass DSP pedalboard for PipeWire.

### Install
Download `Tone-Zone-0.1.0-x86_64.AppImage`, `chmod +x` it and run. Needs PipeWire's JACK library (default on Nobara; otherwise `sudo dnf install pipewire-jack-audio-connection-kit-libs`). No fuse2 needed.

### What's in 0.1.0
- Drag-and-drop board: patch blocks by dragging between 1/4" jacks; realistic sagging cables with plugs, per-cable colours, undo/redo, presets (9 factory presets).
- 174 blocks: pedals, 26 amps, preamps, 17 cabs with draggable mics, loopers and utilities, with mono and stereo versions where it makes sense.
- Layouts inspired by BOSS (DS-1, SD-1, OD-3, BD-2, DS-2, MT-2, HM-2, CH-1, CE-2W, DC-2W, VB-2W, TR-2, BF-3, PH-3, DD-3/7/8, DM-2W, RV-6, TU-3, NS-2, OC-5, PS-6, AW-3, CS-3, GE-7, FV-500, RC-500, RC-600), Ibanez (TS9, TS808, AD9, CS9, FL9), MXR (M169, M222, Phase 90, Dyna Comp, Distortion+, 10-band EQ, Micro Amp, M117R, M234, M288, Smart Gate, Fullbore, Super Badass, Uni-Vibe), Cry Baby, RAT2, PolyTune 3, DigiTech Drop, POD Express and Strymon (CloudBurst, Flint V2, Deco V2, BlueSky V2, El Capistan V2, UltraViolet, Riverside, Fairfax, Sunset, Compadre, Ola, Lex, Brigadier, Brig, DIG, Volante), with working LEDs, screens and footswitch behaviours.
- Native C++ realtime engine as a PipeWire/JACK client: no added latency from the board (pitch blocks excepted); buffer size control; appears in Helvum / qpwgraph; built-in routing panel.
- DSP budget with per-block cost, optional enforcement and automatic quality scaling.
- NAM A1 + A2 (slimmable Full/Lite) and IR support; import many files / folders / .zip as one block with selectable configurations (amp, pedal, preamp or cab graphic).
- TONE3000 tab with "Send to Tone Zone" buttons; downloads go straight to the import dialog.
- Natural-sounding WSOLA pitch shifting; sub-cent tuners down to low B on bass / F# on 8-string, plus polyphonic tuning.
- Capture tab outlines the upcoming NAM-capture workflow.
