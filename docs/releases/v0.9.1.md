Tone Zone **0.9.1**: fixes the Raspberry Pi installer.

### Install
Download `Tone-Zone-0.9.1-x86_64.AppImage`, `chmod +x` it and run. The Raspberry Pi bundle and `install.sh` are attached too.

### Fixes
- **Raspberry Pi installer:** it failed with `curl: (3) URL rejected` and a download address ending in something like `v13 (trixie)`. The installer read the OS's own version into its download address. Raspberry Pi OS Trixie (Debian 13) is supported, and installing on it works now:
  ```bash
  curl -fsSL https://github.com/goglesquirmintontheiii/tone-zone/releases/latest/download/install.sh | sudo bash
  ```
