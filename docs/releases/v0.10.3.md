Tone Zone **0.10.3**: Raspberry Pi input from a USB interface used for both input and output.

### Install
Download `Tone-Zone-0.10.3-x86_64.AppImage`, `chmod +x` it and run. On the Pi, update from the Pi tab or run the install command again:

```
curl -fsSL https://github.com/goglesquirmintontheiii/tone-zone/releases/latest/download/install.sh | sudo bash
```

### Raspberry Pi
- **Input and output on one device:** when JACK could open only the output side of a device (it then quietly runs "playback-only"), the Pi carried on with no input. It now tries larger buffers until both sides open, and if the input never opens, the Audio section says so instead of reporting that audio is running.
- **Ports in use:** the Audio section shows which input and output ports the engine is connected to (for example "In: system:capture_7 (channel 7 of 8)"), so you can switch input channels while watching the Input bar.
