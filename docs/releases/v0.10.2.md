Tone Zone **0.10.2**: Raspberry Pi audio starts reliably and tells you when it can't.

### Install
Download `Tone-Zone-0.10.2-x86_64.AppImage`, `chmod +x` it and run. On the Pi, update from the Pi tab or run the install command again:

```
curl -fsSL https://github.com/goglesquirmintontheiii/tone-zone/releases/latest/download/install.sh | sudo bash
```

### Raspberry Pi
- **JACK really starts:** the Pi now checks that the audio server stayed up. A device that refuses the buffer size (the Pi's headphone jack refuses 128 frames, some USB interfaces too) is tried again at 256, 512 and 1024 frames, and the Audio section says which size it runs at.
- **Audio status:** the Audio section shows "Audio running: JACK on LINE 6 HELIX (in + out), 128 frames x 3" or "No audio" with the reason (device refuses every buffer, device in use by another program, PipeWire library missing, engine could not join).
- **PipeWire picked but not running:** the Pi uses JACK instead of failing.
- **Device in use:** when another program holds the audio device, the Pi says so after one try instead of retrying.
