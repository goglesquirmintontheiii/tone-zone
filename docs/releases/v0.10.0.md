Tone Zone **0.10.0**: the Nautica XL flagship multi-FX, multi-file screen code with a file store and audio, the Advanced Command Center, Atlas Floor and Pixel Quest templates, all templates on the board, neater pedalboards and remembered PipeWire connections.

### Install
Download `Tone-Zone-0.10.0-x86_64.AppImage`, `chmod +x` it and run. Needs PipeWire's JACK library (default on Nobara; otherwise `sudo dnf install pipewire-jack-audio-connection-kit-libs`). Your presets, library and settings are kept.

### Nautica XL
A new flagship multi-FX pedal in the block list, built in (no screen code, so it's light on the CPU).
- **Footswitches:** 14 assignable footswitches plus MODE and TAP / TUNER, each with a small screen showing its block. STOMP, SCENE, PRESET and LOOPER modes. Hold TAP for the tuner.
- **Treadles:** two full size treadles side by side on the right, each with an assignable footswitch above it (pedal on / off by default) and a screen showing its value.
- **Screens:** a big touch screen with a HeadRush style interface (signal chain with drag and drop, block pages, library, scenes, presets, looper, tuner, assignments, I/O routing and global settings), two long strips above it that can show levels, the preset, the focused block, tempo, the pedals or the signal path, and a portrait side screen with the nav buttons, two LED encoders, an XY pad, two sliders and a select encoder.
- **Dials:** a large master volume, two small volume dials (phones and XLR) and 10 dials under the screen.
- **Routing:** paths A and B in series, parallel or dual, 4 effects loops, 8 outputs (4 L/R pairs), phones and XLR, each with its own source.
- **Jacks:** 4 EXT footswitch and 2 EXT expression inputs, an EXT footswitch and an EXT expression output driven by the unit, and a small bar LED for every jack that follows its level.
- **Jack guide:** a page (from I/O routing) that lists every rear jack with what it is, its routing and a live level. IDENTIFY blinks that jack's LED on the rear rail for 3 seconds so you can find it.
- **Presets:** 14 factory presets in 28 slots, 8 scenes each, all at the same loudness as the rest of the library.
- **Pedal Factory template:** the Nautica XL is also a template with 24 coded screens and real audio paths, so you can open it and change anything. The template version has fixed block types per slot, no looper and fixed loop positions.

### Screen code
- **Several files per screen:** `require("util")` loads other code files. Errors name the file and line, and the editor opens the file at the line.
- **File store per pedal:** screens can create, read and write files (text and binary) in a sandbox shared by all screens of the pedal, with a 1 MB budget for code and data together. Files written on the board are saved with the preset.
- **Binary data:** `bin.pack` / `bin.unpack` for your own file formats, plus `fs.readBytes` and `fs.writeBytes`.
- **File editor:** a file list in the code panel with new, rename, copy and delete, a hex view for binary files and a usage bar.
- **Audio:** scripts can read the level, spectrum, waveform, pitch and note starts of any audio jack, start tones and samples with an envelope, and put gain, filters or drive on a jack. Nothing runs unless a script asks for it. New "Script audio" circuit parts (oscillator, noise, envelope, sampler, gain, script input) and two built-in circuits, Script synth and Script sampler.
- `closeKeyboard()` closes the on-screen keyboard from code.

### Pedal Factory
- **Wider pedals:** up to 360 mm.
- **Encoders click in steps:** 24 per turn by default, adjustable per encoder (4 to 64). Screen code events follow each encoder's steps.
- **LED rings:** choose one input for the whole ring or one input per LED (analog sets the brightness), with optional RGB LEDs.
- **New templates:**
  - **Advanced Command Center:** a 360 mm controller with 22 effects in 4 circuits, 2 coded screens that save and recall named presets through the file store, a treadle, 2 RGB ring encoders, 4 encoders, 9 footswitches, an XY pad, sliders, toggles, DIPs, step buttons, meters and RGB LEDs.
  - **Atlas Floor** and **Pixel Quest**, rebuilt with screen code.
  - **Nautica XL** (see above).
- **Templates on the board:** every template is in the block list under "Factory templates". Right-click one on the board and pick "Edit a copy in the Pedal Factory" to make it your own.
- Meter bar LEDs wired from a circuit output now show the level.

### Pedalboards
- **Mounting:** pick Velcro, Screws or Blank. Velcro shows a "Strips per spot" toggle and the velcro colour; Screws shows a "Messy" toggle.
- **Spacing:** pedals get room for their plugs, so they no longer sit on top of each other. Wide pedals take two spots.
- **Neater cables:** cables between pedals on a board run along the gaps between rows instead of across pedals.
- **Presets:** every preset with 3 or more chained pedals now sits on a pedalboard sized to fit (for example Acoustic Lead Pro on a Medium board).

### Board
- **Lighter screens:** big coded screens draw at a lower resolution when they're small on screen. They're sharp when the mouse is over them or above 140% zoom.
- **PipeWire connections are remembered:** links made in Tone Zone, qpwgraph or Helvum come back after an engine or app restart, also for a device you plug in later. Settings has a "Forget" button. Auto-connect is only used the first time.

### Raspberry Pi
- **Audio devices:** the Pi tab lists every sound card the Pi has, and the input and output pickers show the real devices.
- **PipeWire on the Pi:** on a Pi with a desktop (PipeWire running), the device list comes from PipeWire and the engine is connected to the devices you pick.
- **Installer:** fixed on Raspberry Pi OS Trixie (0.9.1).

### Presets
- **Lorna Shore Heavy** and **Lorna Shore Heavy Rhythm**, for 8-string with a low D1 (upper strings in drop G): far more gain than the original Lorna Shore preset, a 5150III lead channel and a VH4 (lead) or a Revv Generator and a Diezel Herbert (rhythm) on different 4x12s, a mud cut before the amps and a tight low shelf plus upper-mid bite after them so the low string stays full and clear and the high strings stay crisp. The lead version has a big ping-pong delay and hall; the rhythm version keeps a short room with the delay ready to switch on.

### Fixes
- Preset thumbnails no longer keep showing missing pedals after you turn plugins off and back on.
